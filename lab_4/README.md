# Лабораторна робота №4

Асинхронний репозиторій, оптимізація запитів EF Core, Dependency Injection.
Варіант 2: вібрація, поле Axis.

Відкрити IoTTelemetryLab.slnx у Visual Studio і запустити Ctrl+F5.
Під час першого запуску застосовуються міграції з ЛР3 та створюються три сенсори.
Програма демонструє N+1, проєкцію, Include і CRUD, потім максимум за осями.
Для другого індивідуального запиту потрібно ввести вісь X/Y/Z і числовий поріг.
Параметри генерації та підключення зберігаються в appsettings.json.
Файл бази розміщується поруч із виконуваним файлом.
